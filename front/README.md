# front — Next.js

React meta-framework for production web apps with App Router, server rendering, route handlers, streaming, metadata, and strong Vercel integration.

## Why choose it

- Best for: SEO websites, Full-stack web apps, Vercel deployments
- Strengths: SSR/SSG/ISR in one framework, Excellent routing and metadata, Can include server APIs
- Trade-offs: More conventions than plain React, Server/client boundary takes practice
- Language/runtime: TypeScript / JavaScript
- Automatic score: 10/10
- Ecosystem: 10/10
- Performance: 9/10
- Developer experience: 9/10
- Learning curve: Medium
- Maturity: Very mature

## Run locally

```bash
cd front
npm run dev -- -H 0.0.0.0 -p 3000
```

Default port: `3000`

Docs: https://nextjs.org/docs
